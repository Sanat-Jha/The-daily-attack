📚 API Documentation

Explore and interact with The Daily Attack API

Introduction

The Daily Attack API provides programmatic access to blog posts and allows authorized users to create new posts. This documentation describes the available endpoints and how to use them.

Authentication

Some endpoints require authentication using an API key. To authenticate, include your API key in the request headers: 

X-API-Key: your-api-key

Endpoints

List All Posts

GET

URL: GET /api/posts/

Authentication: None (public endpoint)

Description: Returns a list of all published posts.

Try it out

Response:

Example Response:

[
  {
    "id": 1,
    "title": "Sample Post",
    "content": "This is a sample post content.",
    "status": "published",
    "created_at": "2023-06-01T12:00:00Z",
    "published_at": "2023-06-01T14:00:00Z",
    "author": "username",
    "tags": [
      {"name": "sample"},
      {"name": "example"}
    ]
  }
]

Search Posts

GET

URL: GET /api/posts/search/?q={query}

Authentication: None (public endpoint)

Description: Searches for published posts matching the query in title or content.

Parameters:

  • q (required): The search query string

Try it out

Response:

Example Response:

[
  {
    "id": 3,
    "title": "Latest Technology Trends",
    "content": "This post discusses the latest technology trends...",
    "status": "published",
    "created_at": "2023-06-05T09:30:00Z",
    "published_at": "2023-06-05T10:15:00Z",
    "author": "username",
    "tags": [
      {"name": "technology"},
      {"name": "trends"}
    ]
  }
]

Get a Specific Post

GET

URL: GET /api/posts/{id}/

Authentication: None (public endpoint)

Description: Returns details of a specific published post.

Try it out

Response:

Example Response:

{
  "id": 1,
  "title": "Sample Post",
  "content": "This is a sample post content.",
  "status": "published",
  "created_at": "2023-06-01T12:00:00Z",
  "published_at": "2023-06-01T14:00:00Z",
  "author": "username",
  "tags": [
    {"name": "sample"},
    {"name": "example"}
  ]
}

Create a New Post

POST

URL: POST /api/posts/create/

Authentication: Required (API Key)

Description: Creates a new blog post.

Try it out

Response:

Request Body:

{
  "title": "New Post Title",
  "content": "Content of the new post",
  "status": "draft", // or "published"
  "tags": ["tag1", "tag2"]
}

Example Response:

{
  "id": 2,
  "title": "New Post Title",
  "content": "Content of the new post",
  "status": "draft",
  "created_at": "2023-06-02T10:00:00Z",
  "published_at": null,
  "author": "username",
  "tags": [
    {"name": "tag1"},
    {"name": "tag2"}
  ]
}

Error Handling

The API uses standard HTTP status codes to indicate the success or failure of a request:

  • 200 OK: The request was successful.
  • 201 Created: The resource was successfully created.
  • 400 Bad Request: The request was invalid or cannot be served.
  • 401 Unauthorized: Authentication is required or failed.
  • 404 Not Found: The requested resource does not exist.
  • 500 Internal Server Error: An error occurred on the server.
